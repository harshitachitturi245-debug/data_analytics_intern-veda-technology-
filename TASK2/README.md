# Exploratory Data Analysis on Iris Dataset

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Iris dataset using Python.

The objective is to identify important patterns, relationships, distributions, and potential outliers in the dataset.

## Objectives

- Understand the structure of the Iris dataset
- Perform basic data cleaning
- Generate summary statistics
- Analyze correlations
- Identify potential outliers
- Compare measurements across Iris species
- Create meaningful visualizations
- Extract the Top 3 insights

## Dataset

The Iris dataset contains 150 observations belonging to three species:

- Setosa
- Versicolor
- Virginica

The numerical features are:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Top 3 Insights

### 1. Petal Measurements
Petal length and petal width show clear differences between Iris species.

### 2. Strong Correlation
Petal length and petal width have a strong positive relationship.

### 3. Species Separation
Setosa is relatively distinct from the other species, while Versicolor and Virginica show some overlap.

## Conclusion

EDA helped identify important patterns, relationships, distributions, and potential outliers in the Iris dataset. The analysis shows that petal-related measurements are particularly useful for distinguishing the three Iris species.
